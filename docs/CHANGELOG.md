# 变更日志 · CHANGELOG

## v1.1.0 — 2026-11-21（简报弹窗 + 摘要清洗修复）

- **总统简报改弹窗**：纸面简报移出页面流，改为页面中的「简报档案」入口条（标题 + 日期 + 头条预告 + 金色「开启简报」钮）；点击入口条按钮、右下角悬浮 📜 钮或导航「总统简报」均打开弹窗——深蓝半透明遮罩 + 轻微背景模糊，纸面置于金色双线框内（宽 min(880px, 94vw)、高 88vh 内部滚动），打开/关闭带淡入上浮过渡，打开时锁定页面滚动。关闭三路：纸面右上 sticky「✕ 封存 CLOSE」钮、点击遮罩、Esc 键。空数据时入口条与弹窗照常呈现（弹窗内为简报空状态）。新增 3 个双语 UI 键（STRINGS 共 57 键），`/api/brief` 与 Telegram 推送不变。
- **摘要 HTML 残骸修复**：聚合源（Google News 等）摘要把 HTML 实体编码（`&lt;ol&gt;&lt;li&gt;&lt;a href=…&gt;`），旧清洗流程先剥标签后解实体，解码还原出的真实标签以原文显示在页面上（线上实测）。修复为「剥标签 → 解实体 → 再剥标签 → 按句末/词界截断」；清洗后仍含 `href=` / CBM 令牌 / 裸 URL 的残骸摘要整段丢弃；渲染层再兜底（卡片、头条、简报、搜索索引统一走 `safeSummary`），修复前已入库的脏摘要同样不外露。
- **本地测试**：Mock harness 新增 Phase E 18 项断言（弹窗结构/位置/双语、实体编码列表摘要入库清洗、未闭合标签残骸丢弃、预置脏数据渲染兜底），合计 **125 项断言全过**。
